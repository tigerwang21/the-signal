AI Trends

Defense

The Pentagon deploys its own ChatGPT and Grok

"ChatGPT Mil" and "Grok for Government" roll out to 3M personnel on GenAI.mil. Anthropic's Claude stays out amid its supply-chain court fight.

techcrunch.com
M&A

Nvidia closes in on acquiring Hugging Face

A reported acquisition would consolidate key developer infrastructure under a major chipmaker, and test the open-source community.

techcrunch.com
Regulation

ChatGPT is the EU's first AI "very large online search engine"

The DSA designation (159M monthly EU users) brings oversight and fines up to 6% of global turnover. First risk assessments are due late November.

thenextweb.com

AI in Education

Policy

Universities mandate AI literacy instead of banning it

Tampa requires a one-credit AI literacy course for all sophomores. NUS makes applied GenAI compulsory for every first-year. Judgment and verification are the core skill.

news.nus.edu.sg
Curriculum

Berkeley's CS 61A adds an AI coding-agent project

The intro course moves from Scheme to Gleam, with checkoffs and a campus AI tutor to verify students still understand their own work.

dailycal.org
Pedagogy

CMU and Johns Hopkins: don't let AI think for you

CMU's GAITAR fellowship and "Effective Coding With AI" stress critical thinking. Johns Hopkins launches an 18-week Agentic AI certificate.

cmu.edu

Agentic Software Engineering

Adoption

Agent adoption hits the mainstream: 90% weekly, 68% daily

JetBrains' survey of 15,000+ developers shows Claude Code (39%) nearly doubling GitHub Copilot (21%), with Codex up roughly 5x to 16%.

blog.jetbrains.com
Production

57% of organizations now run agents in production

LangChain reports quality as the top barrier, observability near-universal at 89% versus 52% for evals, and security as the number two concern.

langchain.com
DevOps

Context engineering, not more intelligence, is the unlock

Agents already write 50-60% of code on some teams. Structured context across the SDLC is what lets them meet DevOps-grade precision.

devops.com

AI Coding Security

CVE

Prompt injection graduates from theory to shipped CVEs

Amazon's Kiro IDE exfiltrates data via a crafted workspace file. NVIDIA's NemoClaw (CVE-2026-65105, CVSS 8.1) poisons a local Ollama model.

thecybersignal.com

A LiteLLM supply-chain breach exposed 2,500+ organizations

Claude Code and Grok each leak via configuration injection
